# CineAI Agent 0.6 — GitHub Pages / Browser-only Edition

واجهة ثابتة تعمل على GitHub Pages، مكتوبة بـ HTML وCSS وJavaScript فقط. لا Python، لا خادم محلي، لا Firebase، ولا قاعدة بيانات سحابية.

## النشر على GitHub Pages

1. فك ضغط الحزمة.
2. ارفع محتويات مجلد `cineai_hub` إلى جذر مستودع GitHub (بما في ذلك `index.html`).
3. افتح إعدادات المستودع: **Settings → Pages**.
4. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط Save.
5. انتظر نشر GitHub Pages ثم افتح الرابط الذي يعرضه GitHub.

## موصل التوليد المباشر

1. افتح تبويب **6. موصل التوليد**.
2. اكتب معرّف Space بصيغة `owner/name`.
3. للمساحات العامة اترك رمز Hugging Face فارغاً. للمساحة التي تتطلب وصولاً خاصاً، أدخل رمزاً مناسباً عند الاستخدام فقط؛ لا تحفظه في الملفات ولا تضعه في GitHub.
4. اضغط **فحص API واستخراج المسارات**. يستخدم الموقع مكتبة Gradio JavaScript الرسمية من jsDelivr CDN، ثم يستدعي `Client.connect()` و`view_api()`.
5. انسخ endpoint المناسب كما يظهر في وثائق API، ثم أدخل مدخلاته في JSON Array وبالترتيب والأنواع المطلوبة.
6. اختر المشهد واضغط إدراج أمر المشهد، ثم عدّل بقية المدخلات إذا كان Space يحتاج مدة أو صورة أو إعدادات إضافية.
7. وافق على تأكيد الإرسال. يعرض الموصل تحديثات حالة المهمة والنتيجة، ثم روابط الملفات الناتجة.

## حدود GitHub Pages والخصوصية

- GitHub Pages يستضيف ملفات ثابتة فقط؛ لا يشغّل Python أو خادماً خلفياً ولا يوفر مجلداً خاصاً لنتائج التوليد.
- يتم الاتصال بمحرك Gradio من متصفح المستخدم مباشرة. يحتاج ذلك إلى اتصال إنترنت وإلى سماح Space بالاتصال من المتصفح (CORS/WebSocket حسب الخدمة). بعض المساحات أو الشبكات قد تمنع الاتصال المباشر.
- الفيديو الناتج يُنزّل عبر المتصفح إلى مجلد التنزيلات الذي يحدده المستخدم. لا يستطيع الموقع الكتابة تلقائياً إلى مجلد `outputs` على GitHub أو إلى مجلد محلي دون اختيار المستخدم.
- مشاريع CineAI محفوظة محلياً في LocalStorage داخل المتصفح، وليست متزامنة بين الأجهزة. صدّر المشروع JSON للاحتفاظ بنسخة احتياطية.
- رمز Hugging Face لا يُحفظ في LocalStorage أو في ملفات المشروع؛ يظل في ذاكرة الصفحة الحالية. لا تضع أي رمز في HTML أو مستودع GitHub. تذكر أن أي رمز تدخله في صفحة ويب متاحة لكودها قد يكون معرضاً للاطلاع من أدوات المتصفح أو الإضافات؛ استخدم أقل صلاحية ممكنة ورمزاً قابلاً للإلغاء.
- عند التوليد تُرسل مدخلات المشهد إلى Space الخارجي المختار. لا ترسل معلومات حساسة.

## تنبيهات التكلفة

- لا توجد عمليات شراء أو ترقية أو دفع تلقائية في CineAI.
- وجود Space عامة لا يعني أنها متاحة بلا حدود؛ قد تتوقف أو تستخدم طوابير أو حصصاً أو تتطلب صلاحية.
- حصص Hugging Face ZeroGPU المجانية محدودة ومتغيرة، ولا يمكن ضمان عدد فيديوهات ثابت.
- لا يضمن هذا الموصل إنتاج فيلم 10 دقائق مجاناً.

## متطلبات موصل Gradio

- Space تعمل فعلياً وتدعم Gradio Client API.
- اسم endpoint صحيح (مثل `/predict` أو اسم مخصص).
- المدخلات مطابقة تماماً لتعريف API.
- قد ترجع بعض المساحات صوراً أو ملفات متعددة أو روابط مؤقتة بدلاً من MP4.

## الملفات

- `index.html` — التطبيق بالكامل وموصل JavaScript.

- `outputs/README.txt` — يوضح أن التنزيل يتم من المتصفح وليس إلى GitHub Pages.
